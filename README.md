# Tab Hollow

Live at https://awesomedonut.github.io/.

This repo holds the built site. Source and development instructions are in [tab-hollow](https://github.com/Awesomedonut/tab-hollow). The current build is from c868fd5.

To update it, run npm ci and npm run build in the source repo, then copy dist/ into this repo and push main. GitHub Pages serves the files from the repository root.

The previous homepage is at [portfolio.html](https://awesomedonut.github.io/portfolio.html). Its other pages and assets are still here.

Bundled artwork keeps its original licenses and credits; see [the credits page](https://awesomedonut.github.io/credits.html).
